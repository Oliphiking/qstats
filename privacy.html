Privacy Policy – Q Stats

Last updated: June 2026

This Privacy Policy explains what data the Discord bot Q Stats ("the Bot", "we") processes when used on Discord servers ("Servers", "Guilds").

1. Operator / Contact

Q Stats is a free, non-commercial hobby project provided "as is", without any guarantee of availability, accuracy, or fitness for a particular purpose. Contact is provided exclusively via Discord:

  • Discord username: szvn8
  • Discord username: 3bvi

2. What data is processed?

The Bot only processes data provided through the Discord API, to the extent necessary for its features:

  • Discord user IDs of members on a server where the Bot is active.
  • XP and level values, generated by sending messages.
  • Invite statistics (e.g. how many members a user has invited).
  • Role assignments, automatically granted or removed by the Bot based on activity, server boosts, server tags, or status (custom status containing a server invite link).
  • Server settings configured by administrators (e.g. channel IDs, role IDs, welcome messages).

3. What is NOT stored?

  • The Bot does not permanently store message content. Message text is only processed live to recognize and execute commands (prefix .) and is not saved to any database.
  • The Bot does not permanently store presence/activity data. Status information (e.g. custom status) is only checked live to trigger automatic role assignments.
  • No message content or activity data is used to train any AI/machine learning models.
  • No real names, email addresses, or other sensitive personal data are collected.

4. Storage location and retention

The data listed above that is permanently stored (user IDs, XP, invite counters, server settings) is stored in a database on the server infrastructure used to run the Bot, currently provided by the hosting provider Wispbyte. Wispbyte acts solely as a technical hosting provider for the Bot's database and runtime, and does not have independent access to or use of the data beyond providing the underlying infrastructure. Data is deleted once the Bot is removed from a server, or upon a verified deletion request from the affected user.

We reserve the right to change our hosting provider at any time, without prior notice, at our sole discretion. We make a reasonable, good-faith effort to choose a provider we consider secure and trustworthy, but we provide no guarantee whatsoever regarding the security, availability, or data handling practices of any current or future hosting provider.

5. Disclosure to third parties

No processed data is shared with, sold to, or used by any third parties for their own purposes. Data is used solely to provide the Bot's features on the respective Discord server. The only exception is the hosting provider mentioned in Section 4, which stores the data on our behalf as part of providing server infrastructure.

6. User rights

Users may request information about data stored about them, or request its deletion, at any time via the Discord contacts listed above.
